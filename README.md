# Invitation de mariage — Fatim & Zoum

Ce dossier contient l'invitation de mariage numérique, prête à être publiée gratuitement sur GitHub Pages.

## Mettre l'invitation en ligne (GitHub Pages)

1. Va sur [github.com](https://github.com) et connecte-toi (ou crée un compte gratuit).
2. Clique sur **New repository** (nouveau dépôt).
   - Donne-lui un nom, par exemple `invitation-fatim-zoum`.
   - Laisse-le en **Public**.
   - Clique sur **Create repository**.
3. Sur la page du dépôt, clique sur **Add file** → **Upload files**.
4. Glisse-dépose le fichier `index.html` (celui de ce dossier) dans la zone d'upload.
5. Clique sur **Commit changes** en bas de page.
6. Va ensuite dans l'onglet **Settings** du dépôt → section **Pages** (dans le menu de gauche).
7. Sous **Build and deployment** → **Branch**, choisis `main` et le dossier `/ (root)`, puis clique sur **Save**.
8. Patiente 1 à 2 minutes : GitHub affiche un lien du type
   `https://ton-nom-utilisateur.github.io/invitation-fatim-zoum/`
   C'est ce lien que tu peux partager avec tes invités.

## Remarques

- Le fichier `index.html` est autonome (une seule page) — il contient déjà toutes les photos et images, aucun autre fichier n'est nécessaire.
- Si tu modifies le contenu plus tard, il suffit de re-uploader un nouveau `index.html` par-dessus l'ancien (bouton **Add file** → **Upload files** à nouveau).
- Le dépôt doit rester **Public** pour que GitHub Pages fonctionne gratuitement.
